Ad-free YouTube for LG webOS TVs, with SponsorBlock, Return YouTube Dislike, DeArrow, playback speed and a programmable remote.

This build: webOS 22 and newer (2022 and newer TVs). Lighter and faster than the build for older TVs. Not for webOS 3-6: on those TVs, add the other repository link (see the project page).

  • No ads on Home, Search and Shorts, and no QR-code, shop or paid-promotion overlays during playback
  • SponsorBlock: every category, auto or manual skip, each in its own colour on the seek bar
  • Playback speed from 0.25x to 2x with the pitch kept (webOS 4 and newer; on webOS 4-6 and 22 with AAC audio only)
  • All four colour buttons and 0-9 can run an action: Sleep Timer, Audio-Only Mode, chapters, subtitles, speed and more
  • Auto-translated subtitles in about 30 languages, and the original audio in place of dubbed tracks
  • Feed filters: Shorts, live, watched, short or old videos, Mixes, blocked channels and title keywords
  • OLED care: a black overlay on the Red button, a true-black interface, Audio-Only Mode
  • An update check, and What's New after each update

Before installing: uninstall the official YouTube app. The settings open with the Green button, or with the fox button the Magic Remote pointer shows.

Updates: press Update on this entry. Keep only one repository link for this app: every other entry with the id youtube.leanback.v4 (the older "YouTube AdFree" in the default repository, or another fork's link) replaces this build when you press its Update.
