# Security policy

## Supported versions

Only the latest release gets fixes. Please check that a problem still happens
on it before reporting.

## Reporting a vulnerability

Please report security problems privately, not in a public issue: open the
[Security tab](https://github.com/foxi69/youtube-webos/security) and press
**Report a vulnerability**. Only the maintainer sees the report.

Helpful to include:

- the app version and the package (webOS 22+ or legacy),
- the webOS version of the TV,
- what an attacker could do, and the steps that show it.

You should get an answer within a week. A fix goes into the next release, and
the report is published as a security advisory once the fix is out, crediting
you if you like.

## Scope

The app runs inside YouTube's TV web app on the TV. Reports about it are in
scope: the settings panel, the ad and tracking filters, and the requests it
makes to SponsorBlock, DeArrow and Return YouTube Dislike. YouTube itself,
LG's webOS and the Homebrew Channel are not; please report those to their
owners.
